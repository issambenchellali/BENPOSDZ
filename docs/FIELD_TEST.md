# قائمة الاختبار الميداني قبل الإطلاق (Field Test Checklist)

> الغرض: التحقق من أن التطبيق يعمل على **أجهزة حقيقية** وفي **سيناريوهات الاستخدام اليومي**، وليس على المحاكي فقط.
> يُنفَّذ على جهازين على الأقل: جهاز أندرويد 10+ وجهاز أندرويد 8–9 إن أمكن.

## 0) الحزمة المطلوبة
- [ ] `dz.benpos.pos-Signed.apk` (نسخة Release موقّعة — الإصدار 1.1.0 أو أحدث)
- [ ] تأكيد التوقيع: `apksigner verify --print-certs` → يجب أن يعرض `CN=BENPOSDZ POS` (وليس "Android Debug")

## 1) التثبيت والإقلاع
- [ ] التثبيت ينجح على كلا الجهازين (تمكين "مصادر غير معروفة")
- [ ] التطبيق يفتح ويعرض شاشة تسجيل الدخول
- [ ] الأزرار تستجيب للمس (شريط التنقل السفلي يعمل)
- [ ] تسجيل الدخول بـ `admin` / `1234` ينجح (SQLite المحلي يعمل على أندرويد)
- [ ] إغلاق التطبيق وإعادة فتحه — تبقى الجلسة/البيانات محفوظة

## 2) المزامنة Offline-First
- [ ] **بشبكة متصلة**: أضف منتجاً جديداً على الهاتف → يظهر فوراً في قائمة المنتجات
- [ ] **وضع الطيران**: أضف منتجاً/عملية بيع → لا ينهار التطبيق، البيانات تُخزّن محلياً
- [ ] **عودة الشبكة**: خلال 15–30 ثانية تُرفع البيانات إلى السحابة (تفعيل `CloudSyncEnabled` + Supabase)
- [ ] جهازان بنفس الحساب: تعديل على جهاز يظهر على الآخر بعد المزامنة
- [ ] لا تعارض/فقدان للبيانات (آلية `UpdatedAt`)

## 3) الطباعة والمشاركة
- [ ] زر "طباعة" في صفحة الفاتورة يفتح نافذة طباعة النظام
- [ ] خيارات: طابعة النظام، **حفظ PDF**، مشاركة
- [ ] مشاركة الفاتورة عبر واتساب/بريد/تطبيقات أخرى تعمل (نص/PDF)
- [ ] طباعة باركود المنتج تعمل

## 4) التفعيل (Licensing)
- [ ] الإعدادات ← التفعيل: **Machine ID** يظهر بصيغة `NNNN-NNNN`
- [ ] `internal-codegen -MachineId <المعرّف>` يولّد كوداً يقبله التطبيق (مع نفس `ActivationSecret`)
- [ ] بعد التفعيل تظهر "البرنامج مُفعَّل" مع تاريخ انتهاء
- [ ] **التحقق الحرج**: التفعيل باقٍ بعد إعادة تشغيل التطبيق
- [ ] جهازان مختلفان → Machine ID مختلفان، وكود كل جهاز لا يعمل على الآخر
- [ ] نسخة تجريبية 15 يوماً تعمل بلا كود (مؤقتة)

## 5) الأداء والاستقرار
- [ ] استخدام مكثف (بحث/بيع/طباعة متكررة) دون تباطؤ أو تجمّد
- [ ] التطبيق مفتوح ساعات — مراقبة استهلاك البطارية/الذاكرة (Android Developer Options → Running Services)
- [ ] لا إغلاق مفاجئ في الخلفية بعد تصغير التطبيق
- [ ] اتجاه الشاشة (عمودي/أفقي) لا يكسر التخطيط

## 6) أمان وسلامة
- [ ] محاولة إعادة ضبط ساعة الجهاز للخلف → تفعيل حماية التلاعب بالتاريخ
- [ ] `MySQL_Pass`/`SupabaseKey` محفوظة مشفرة (AndroidKeyStore) — لا تظهر نصاً في أي مكان
- [ ] تحديث APK فوق نسخة أقدم يبقي التفعيل والبيانات (توقيع واحد ثابت)

## إرشادات التقرير
- لاحظ **الجهاز والطراز** + **نسخة أندرويد** + **الخطوة التي فشلت** + **رسالة الخطأ** (من الإعدادات ← 📊 السجل).
- أرفق لقطة شاشة إن أمكن.
