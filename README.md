  BENPOS DZ — دليل نشر وتثبيت البرنامج خطوة بخطوة
  نظام إدارة المبيعات (نقطة بيع، مخزون، فواتير، مالية)
  الإصدار: Enterprise  |  الوضعان: محلي SQLite / شبكي MySQL
============================================================

------------------------------------------------------------
1) المتطلبات
------------------------------------------------------------
- جهاز يعمل بنظام Windows 10 أو Windows 11 (64 بت).
- لملف التثبيت: يكفي نسخ مجلد البرنامج كاملاً، أو ملف التثبيت
  (self-contained) — لا يحتاج إلى تثبيت .NET بشكل منفصل.
- للوضع الشبكي (عدة أجهزة): جهاز خادم عليه MySQL Server 8+
  وباقي الأجهزة على نفس الشبكة المحلية.

------------------------------------------------------------
2) تثبيت البرنامج
------------------------------------------------------------
1. انسخ مجلد البرنامج إلى جهاز العميل (مثلاً C:\BENPOS).
2. شغّل BENPOSDZ.exe.
3. عند أول تشغيل تظهر شاشة الدخول.

------------------------------------------------------------
3) الحسابات الافتراضية (لقاعدة بيانات فارغة)
------------------------------------------------------------
- المدير:   admin  /  123
- البائع:   123    /  123

⚠️ بعد أول دخول: غيّر كلمة مرور المدير فوراً من صفحة
   "المستخدمون" لأسباب أمنية.

------------------------------------------------------------
4) الوضع الأول: محلي (SQLite) — جهاز واحد
------------------------------------------------------------
- من شاشة الدخول اختر "محلي (SQLite)".
- لا حاجة لأي خادم، كل البيانات تُحفظ في ملف محلي
  StockDB.db داخل مجلد التطبيقات.
- مناسب لصاحب محل يريد برنامجاً على جهاز واحد فقط.

------------------------------------------------------------
5) الوضع الثاني: شبكة محلية (MySQL) — عدة أجهزة
------------------------------------------------------------
أ) على جهاز الخادم:
   1. ثبّت MySQL Server 8+.
   2. نفّذ سكريبت إنشاء القاعدة والمستخدم من الملف:
        Database\mysql_setup.sql
      (ينشئ قاعدة benposdb ومستخدم benpos_user للأجهزة
      المحلية فقط — لا يستخدم '%' نهائياً).

ب) من ملف إعدادات MySQL (my.ini) تأكد من:
       bind-address = 0.0.0.0
       skip-networking = 0
      ثم أعد تشغيل خدمة MySQL.

ج) سجّل اسم جهاز الخادم ثابتاً داخل الشبكة (اختياري ومفيد):
      الإعدادات > النظام > إعادة تسمية هذا الكمبيوتر
      مثال: BEN-SERVER
      (بهذا لا تحتاج IP ثابت — الاسم يعمل حتى لو تغير الـ IP)

د) على كل جهاز (بما في ذلك جهاز الخادم نفسه):
   1. اختر وضع "شبكة (MySQL)".
   2. في حقل الخادم اكتب اسم الجهاز (مثل BEN-SERVER)
      أو الـ IP، أو اضغط زر "اكتشاف الخادم" ليفحص البرنامج
      الشبكة المحلية ويعرض الأجهزة التي تشغّل MySQL — اخترها
      بنقرة واحدة.
   3. اسم المستخدم: benpos_user  وكلمة المرور التي وضعتها.
   4. اضغط "حفظ الإعدادات" ثم سجّل الدخول.

🔐 تنبيه أمني هام:
   - لا تفتح المنفذ 3306 من الراوتر للإنترنت.
   - لا تشارك كلمة مرور benpos_user خارج الشبكة.

------------------------------------------------------------
6) إنشاء مفتاح التفعيل وإرساله للزبون (أدوات المطور)
------------------------------------------------------------
يوجد في هذا المجلد (internal-tools):

- internal-generator   ← الأداة الرئيسية (شاشة رسومية)
  - internal-1y            ← تشغيلها بمدة سنة
  - internal-3y           ← تشغيلها بمدة 3 سنوات
- internal-codegen           ← توليد كود التفعيل (6 خانات) لجهاز معين

طريقة إنشاء مفتاح فلاشة:
   1. افتح internal-3y (أو internal-1y).
   2. اكتب اسم المتجر بدقة كما سيظهر في الفاتورة.
   3. حدد عدد الأجهزة المسموح بها (افتراضياً 5).
   4. اختر مكان الحفظ (سطح المكتب أو فلاشة موصولة).
   5. اضغط "إنشاء مفتاح التفعيل" — يتولد ملف benpos.lic.
   6. أرسل الملف للزبون ليضعه في فلاشة فارغة.

طريقة التفعيل عند الزبون:
   1. افتح البرنامج > الإعدادات > تبويب "التفعيل".
   2. وصل الفلاشة واكتب اسم المتجر (نفس الاسم في المفتاح)
      ثم اضغط "تفعيل بالفلاشة".
   3. سيتم قفل اسم المتجر وإضافة مدة الترخيص.

ملاحظة: يمكنك أيضاً توليد كود تفعيل لمدة سنة عن بُعد
(بدون فلاشة) عبر تبويب "تفعيل بكود سري" باستخدام
رقم الجهاز Machine ID الظاهر في نفس الصفحة.

------------------------------------------------------------
7) المزامنة السحابية (Supabase) — اختيارية
------------------------------------------------------------
- من الإعدادات > تبويب "الاتصال" فعّل "المزامنة السحابية".
- أدخل Supabase URL والمفتاح (تُخزَّن محلياً فقط).
- تُرفع المنتجات والأشخاص والفواتير والمصاريف تلقائياً.
- يمكنك مزامنة يدوياً من زر ☁️ في الشريط الجانبي.
- الجداول المتزامنة (اسمها في السحابة بحروف صغيرة):
  products · persons · orders · order_details · expenses · product_types
- أنشئ/أصلح هذه الجداول في Supabase عبر ملف:
  Database\supabase_setup.sql  (Supabase Dashboard → SQL Editor → Run)
  السكريبت idempotent: يمكنك تشغيله أكثر من مرة بأمان.

------------------------------------------------------------
8) قوالب الطباعة
------------------------------------------------------------
- الإعدادات > تبويب "الطباعة": عدّل قوالب
  الفاتورة (A4) وبون التسليم (BL) والوصل (80mm) بالسحب والإفلات.
- معاينة حية، طباعة تجريبية، وتصدير Word.

------------------------------------------------------------
9) النسخ الاحتياطي والتدقيق
------------------------------------------------------------
- الإعدادات > تبويب "النسخ الاحتياطي":
  * إنشاء نسخة احتياطية / استعادة أحدث نسخة.
  * تنظيف الأخطاء العشرية.
  * "فحص دقة الحسابات المالية" — يتحقق من مطابقة تفاصيل
    الفواتير مع الإجماليات والمدفوعات والديون ويظهر أي خطأ.
  * منطقة الخطر: محو كل العمليات المالية (مع نسخة تلقائية).

------------------------------------------------------------
10) السجل (System Log)
------------------------------------------------------------
- الإعدادات > تبويب "السجل": يعرض كل العمليات والأخطاء.
- ملف السجل: System.log داخل مجلد التطبيقات المحلية
  (يمكن فتح مجلده بزر واحد لمساعدتنا في تحليل الأخطاء).

------------------------------------------------------------
11) حل المشاكل الشائعة
------------------------------------------------------------
- "تعذر الاتصال بالخادم":
  * تأكد أن MySQL يعمل على الخادم.
  * جرّب زر "اكتشاف الخادم" أو اكتب اسم الجهاز.
  * تأكد من bind-address وallow ان المتصفح محلي.
- نسيت كلمة المرور: احذف ملف StockDB.db (تُمسح البيانات) أو
  استعد نسخة احتياطية، ثم سجّل الدخول بالحسابات الافتراضية.
- مشاكل بعد التحديث: أنشئ نسخة احتياطية أولاً ثم حدّث.
